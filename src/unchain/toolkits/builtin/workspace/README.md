# Workspace Toolkit

`WorkspaceToolkit` is the public workspace and coding surface for first-party
consumers.

It exposes canonical coding tools such as `read`, `write`, `edit`, `glob`,
`grep`, `shell`, and `lsp`, while keeping stable compatibility names such as
`read_file`, `write_file`, `delete_file`, `move_file`, `terminal_exec`,
`pin_file_context`, and `unpin_file_context`.
