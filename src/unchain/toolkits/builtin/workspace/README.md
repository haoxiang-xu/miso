# Workspace Toolkit

`WorkspaceToolkit` is the compatibility workspace surface for first-party
consumers that still use legacy workspace tool names.

It wraps the current `CoreToolkit` file, search, and shell behavior behind
stable names such as `read_file`, `write_file`, `delete_file`,
`move_file`, `terminal_exec`, `pin_file_context`, and
`unpin_file_context`.
